# Log Ingestion Engine

A centralized log ingestion system that collects, validates, enriches, and routes logs from multiple services.

## Project Status
- Phase 1: Ingestion & Validation (In Progress)
- Phase 2: Routing & Enrichment (Pending)
- Phase 3: Storage & Queuing (Pending)
- Phase 4: Monitoring & Reporting (Pending)

## Tech Stack
- Node.js/TypeScript (or your preferred language)
- RabbitMQ
- SQLite
- REST API
